# Elevator Waiting Simulator

日本のオフィス・マンションのエレベーターホールを、HTML / CSS / JavaScriptだけで再現した静的サイトです。

## GitHub Pagesで公開する

このフォルダー内の `index.html`、`style.css`、`script.js` をリポジトリの公開対象へ置き、GitHubの **Settings → Pages** でブランチを選択してください。ビルド工程や外部ライブラリは不要です。

## 操作

丸い下向きボタンを押して待つだけです。ブラウザの音声再生制限に対応するため、最初のボタン操作で音声が有効になります。
