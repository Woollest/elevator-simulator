# Elevator Waiting Simulator

日本のオフィス・マンションのエレベーターホールを再現した静的サイトです。表示と状態管理にはReact、進行方向と呼び方向から停止を判断する制御コアにはRust製WebAssemblyを使用しています。

## GitHub Pagesで公開する

リポジトリをGitHub Pagesの公開対象に設定するだけで動作します。Rustソースを変更した場合のみ、`wasm32-unknown-unknown` 向けに `elevator_core.wasm` を再生成してください。

## 操作

上下いずれか、または両方の呼びボタンを押して待ちます。進行方向と反対の呼び出しは一度通過され、折り返した後に処理されます。ブラウザの音声再生制限に対応するため、最初のボタン操作で音声が有効になります。
